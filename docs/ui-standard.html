OneMail UI 标准

全站唯一的设计规范。数值对应 public/style.css 开头的变量;改样式先改这里,再改变量,不在单个页面里写零散数值。参考的产品:Linear、Stripe、Microsoft 365 管理中心。

设计原则颜色文字间距圆角与尺寸图标布局组件交互屏幕宽度文案

1. 设计原则

简洁整体白底,层次靠留白和 1px 细线区分,不用灰底叠白块,不加装饰阴影
蓝色克制品牌蓝只给主按钮、链接、选中状态和未读圆点;一屏最多一个主按钮
操作就近常用操作放在它作用的位置:表格工具栏在表格框里,行操作收进行尾「⋯」,列表快捷操作在悬停时出现
少打扰设置改了才出现保存条;能一步完成的不开弹窗(临时邮箱一行创建)

阴影只给浮层:下拉菜单和保存条用轻阴影,弹窗用重阴影;页面里的卡片和按钮不加阴影

6. 图标

风格线条图标,24 网格,线宽 1.75,圆头圆角
尺寸18:侧栏、读信工具栏;16:按钮、表格、菜单、搜索框;40:空状态
颜色侧栏和工具栏图标平时灰,悬停或选中变深;菜单里的删除图标随文字变红
规则图标必须和内容相关;只有图标的按钮必须有悬停提示

7. 布局

外框没有顶栏。左侧栏(浅灰底)+ 右侧内容(白底),中间一条细线
侧栏从上到下:Logo 和名称 → 搜索(按 / 聚焦)→ 写信 → 邮箱切换(管理员)→ 文件夹 →「工具」临时邮箱 →「管理」概览、账号和地址(管理员)→ 底部:设置、自己的头像和地址(点开有退出登录)
收件箱信件列表 + 读信两栏。列表顶部:文件夹名、收件地址筛选、刷新;下面一排「全部 / 未读 / 带附件」
页面页头(标题 + 一句说明,右边放主要操作)→ 下划线标签(如有)→ 内容
管理「概览」单独一页;「账号和地址」下分标签:账号、别名和群组、临时邮箱、发信、品牌、记录

9. 交互

信件列表悬停时右上角出现:星标、标为已读/未读、删除(垃圾箱里是移回);未读左侧蓝点
读信顶部工具栏只放图标(回复、全部回复、转发 | 星标、未读、下载、删除);正文下方放「回复」「全部回复」「转发」按钮
搜索侧栏搜索框输入即搜;按 / 聚焦,按 Esc 清空;在其他页面搜索会自动回到信件列表
临时邮箱页面顶部一行:输入前缀(或骰子随机)+ 有效期 → 「创建并复制」,不开弹窗
设置改了内容,底部浮出「有修改还没保存」+ 撤销 / 保存修改;一次保存整页
危险操作删除、停用、断开先确认,写明后果

10. 屏幕宽度

> 1100 电脑收件箱两栏;概览指标 4 列;设置左右两栏;页面左右 40
761–1100 平板收件箱单栏(点信进入读信);指标 2 列;图表和排行上下排;页面左右 28
≤ 760 手机顶部出现菜单条,侧栏从左滑出;设置改为上下排;表格每行一张卡片,「⋯」固定在卡片右上;页面左右 16

11. 文案

标点中文用全角标点;中英文、中文与数字之间空一格
标题说明页面和分区标题下各一句话,说清这里做什么,不超过一行
按钮动词开头,2–6 个字:新建账号、创建并复制、保存修改
提示成功用短句(已保存、已复制);失败说原因和怎么办
